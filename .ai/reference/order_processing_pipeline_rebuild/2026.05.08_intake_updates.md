## End-to-end pipeline (target slice)

Ordered flow from PO creation through disputes. Use this as the canonical step list when tracing **which models/APIs** own each transition.

2. **Edit Order**
3. **Preprocess: Standardize Manifest**
4. **Preprocess: AI Cleanup**
5. **Preprocess: Final Manual Review**
6. **Receiving: take photos**
7. **Processing: Build Data**
8. **Processing: Check in items and print labels**
9. **Processing: Close PO**
10. **Disputes: Handle disputing undelivered or bad-condition items**
