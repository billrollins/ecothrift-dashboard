release(v2.45.0): floorplan print dialog, flip, constrained move/scale

Release: v2.45.0

- Print dialog (editor header): live preview + toggles - black/white, element style (images / solid fill / outline only), element labels, zones + zone labels, drawings, text labels, info blocks, grid, border weight, plan border, inactive elements; one-click Outline preset for printing blank layouts to sketch new configurations on. Landscape browser print via dedicated window.
- Flip horizontal/vertical: single elements mirror their content (flipH/flipV, rotation-aware, captions stay readable); multi-selections mirror the arrangement about the center; paths mirror point-wise.
- Group scaling: multi-select corner handles scale positions and sizes about the opposite corner; wall-like thin elements (aspect >= 3) keep their depth so scaling a room outline lengthens walls without fattening them.
- Shift constrains: moving locks to the dominant axis (no diagonals); resizing (single or group) changes exactly one dimension.
- Tests: 5 new vitest cases (222 OK); tsc + production build green.
