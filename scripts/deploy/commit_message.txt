release(v2.36.0): TARS end-to-end lifecycle and Restoration Returns

Release: v2.36.0

Close the TARS restoration lifecycle so bench Disposition actually returns items to Processing with the achieved grade, parts-needed flows park and resume cleanly, and Processing can find returned items to retag and price.

- complete_restoration_job moves items by destination, writes ItemHistory + grade snapshot, refreshes processing denorm (migration 0077 processing_handled_at)
- GET restoration-jobs/returns/ and POST mark-handled/ for Processing handoff tracking
- receive_parts_request sets pending.partsReceived on the bench
- Dashboard active_jobs / returns_pending metrics; Restoration Returns page with print tag, set price, mark handled
- TARS bench: request parts auto-pending, disposition from pending, parts-received banner; dead UI removed
